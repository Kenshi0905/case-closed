Generated with the built-in image-generation tool for Case Closed. The current dialogue portraits are six individual transparent images in `public/assets/portraits/`, displayed with `object-fit: contain` so complete poses and held props remain visible. Missing images use the original code-drawn pixel portrait fallback.
