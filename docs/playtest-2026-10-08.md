# Timed playtest — 8 October 2026

Tested the hosted Case Closed build in two isolated private samples, approximately 17:26–17:38 IST. No implementation, hosting, or live-workshop changes. The timebox ran about two minutes over to finish the browser reveal and save this report.

## Coverage

- Browser: all six opening panels, choices 3 → 1 → 2 → 3 → 2 → 1; sample-cast entry; investigation map and suspect menu; one custom compound question; facilitator phase advancement; accusation, ballot close, culprit reveal, and learning/debrief screen.
- Independent hosted API sample: ten varied questions across all six suspects; phase-4 instruction override; voting, duplicate-vote rejection, reveal, and phase 6.
- The eight-minute writing period was skipped using the sample cast. This was not a full 50-player rehearsal. All five map objects were not physically collected in this run. Credits, sound quality, offline fallback, and all portrait variants were not retested. Browser and API runs used separate cases; this was broad end-to-end coverage, not one exhaustive detective playthrough.

## What worked well

- The opening now feels like a game screen: framed narration, visible numbered choices, a selected state, and clear progression. The six choices completed without a gameplay blocker.
- Selected opening details appeared in the reveal: the unfinished report, checking records, passing lighted workstations, and joining the group all carried into the final timeline.
- Isha's portrait was fully framed in the narrow view, with hands and flask visible; the bottom dialogue and question controls remained usable. The former side-cropping was not present for this portrait.
- Explicit watch and flask questions returned complete case facts and correctly awarded their clues.
- Ten API questions completed without server/network errors. Median request time was 2.90 seconds; range 1.22–6.45 seconds, including one fast guarded refusal. Nine accepted local replies were archived. Browser reply also appeared in its sample's archive.
- Forced confession and instruction override were refused without awarding clues. Duplicate voting was rejected and the total remained one.
- Browser accusation, reveal, true timeline, motive explanation, and learning screen all opened successfully. The independent API path also reached phase 6.
- Live workshop state was identical before and after: phase 1, revision 2, zero participants, zero suspects, unpublished.
